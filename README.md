## ✨ 功能特色

- 不需要電腦，也能完成 sid9tool 首次安裝

- 用免費開發者帳號簽名並安裝 IPA 到你的裝置

- 內建容器，不再需要另外安裝 LiveContainer

- 7 天自動重簽 App，永不掉簽
