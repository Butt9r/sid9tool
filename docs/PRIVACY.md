# sid9tool 隱私政策 / Privacy Policy / 隐私政策

sid9tool 是本地優先（local-first）的工具，尊重你的隱私 / sid9tool is a local-first utility and respects your privacy / sid9tool 是本地优先的工具，尊重你的隐私。

## Data Handling / 資料處理 / 资料处理
- **On-device only (by default):** Pairing 匯入、.p12 憑證、.mobileprovision、簽名結果與容器設定皆存於 App Sandbox，**不上傳任何伺服器** / Pairing imports, `.p12` certificates, `.mobileprovision` profiles, signing results and container settings stay in the App Sandbox and are **never uploaded** / Pairing 导入、.p12 证书、.mobileprovision、签名结果与容器设置均保存在 App Sandbox 内，**从不上传**
- **Featured feed (opt-in network):** 「精選」分頁可從 `featured.json` 拉取遠端清單，僅請求公開 raw URL，不附帶任何個人資訊，並附本機快取 / The Featured tab fetches a public `featured.json` feed; the request carries **no personal data**, and a local cache is used offline / 「精选」分页仅请求公开的 featured.json 地址，**不携带任何个人数据**，离线时读取本地缓存
- **No accounts, no analytics, no ads, no crash reporting** / sid9tool 無帳號、無分析、無廣告、無 crash 回報 / sid9tool 无账号、无分析、无广告、无 crash 回报
- **No data selling or third-party sharing** / 不出售、不共享任何使用者資料 / 不出售、不共享任何用户数据

## Your Rights / 你的權利 / 你的权利
- Delete the app to remove all local data instantly. / 刪除 App 即可立即移除所有本機資料。 / 删除 App 即可立即移除所有本地资料。
- Language choice (`zh-Hant` / `en` / `zh-Hans`) and consent flags are stored only in `UserDefaults`.
